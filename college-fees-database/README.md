# College Fees Database

This project is a simple SQL database designed to manage and track student semester fee payments.

## Features
- It store student names and semester information
- It tracks fees amounts and payment status
- Identify unpaid students
- Record payment dates
- Run analysis queries for reporting

## Technologies Used
- MySQL

## Files
- `schema.sql` → database structure
- `data.sql` → sample data
- `queries.sql` → sample queries for analysis

## How to Use
1. Run `schema.sql` to create the database and table.
2. Run `data.sql` to insert sample student data.
3. Run `queries.sql` to analyze data, e.g., total fees collected or unpaid students.
